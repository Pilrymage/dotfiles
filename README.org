* Pilrymage 的个人配置

使用 chezmoi 管理的跨平台个人配置。稳定配置统一放在 =~/.config=，Windows、macOS 与 Linux 的应用入口由模板或符号链接连接到同一份配置。

* 使用方法
#+begin_src bash
  chezmoi init git@github.com:Pilrymage/dotfiles.git
  chezmoi diff
  chezmoi apply
  chezmoi add ~/.config/example # 只添加经过审查的目标
  chezmoi git -- push origin main
#+end_src
* 内容
1. =~/.emacs.d= 由 chezmoi external 引用独立 Git 仓库。
2. Rime、mpv、Neovim 与 PowerShell 等使用 =~/.config= 作为稳定配置源。
3. Windows、macOS、Linux 专属入口由 =.chezmoiignore.tmpl= 隔离。
4. 国内软件镜像及工具配置。

目录布局、秘密注入方式和本机配置纳入范围见 [[file:STRUCTURE.md][STRUCTURE.md]]。
